## Current Documentation Scope

The documentation focuses on Theia OS 0.15, which marks the completion of the Basic Functionality phase.

Descriptions of implemented functionality must reflect verified behavior. Planned features and future architectural concepts must be identified as such.

## Project Principles

Theia OS is an independent operating system developed from the ground up.

Its development prioritizes:

1. Core functionality.
2. Security.
3. Visual interface.

The operating system uses its own boot process and kernel architecture. Its source code remains closed-source, while public technical documentation describes the project's design and behavior.
