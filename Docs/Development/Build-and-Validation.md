# Build and Validation

Theia OS has a proprietary internal process for producing and validating its
published images. That process is part of the private implementation of the
project.

This repository documents the result of the process, not its commands, scripts,
parameters, procedures, tool configuration, or internal diagnostics. No build
instructions are published, and no source tree is distributed.

Published images are validated before release. The documented validation of the
0.18 image confirmed that a complete system boots to the Theia OS Mashel banner
and the `theia>` prompt in the reference virtual environment.

For capability status, see [Development Status](Development-Status.md). For
version order, see [Roadmap](Roadmap.md).
